Baseline scenario: Linear Regression

scenario_id = baseline_linear_regression

Plain OLS (on standardized features) per (target, horizon) cell, on the baseline feature set — seasonality, lags, and (load only) weekday features. No weather or capacity information yet. See docs/modeling_plan.md for the full plan and dhf/features.py for the feature definitions.

This notebook and 05_baseline_lightgbm.ipynb follow an identical structure (features used -> MAE/RMSE -> actual-vs-predicted -> error analysis -> feature importance) so the two models are easy to compare section by section; the shared computation/plotting code lives in dhf/reporting.py.

import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

import pandas as pd

from dhf.paths import ProjPaths
from dhf.reporting import (
    describe_feature_sets,
    fit_and_evaluate,
    plot_actual_vs_predicted,
    plot_importance_heatmaps,
    plot_mae_by_horizon,
    plot_rolling_error,
    plot_scatter_actual_vs_predicted,
)
from dhf.scenarios import save_scenario_metrics
from dhf.splits import EXAMPLE_WINDOWS
from dhf.viz import KNOWN_SCENARIO_COLORS, MODEL_LABELS

paths = ProjPaths()
paths.ensure_directories()

SCENARIO_ID = "baseline_linear_regression"
COLOR = KNOWN_SCENARIO_COLORS[SCENARIO_ID]
MODEL_LABEL = MODEL_LABELS["linear_regression"]

panel = pd.read_parquet(paths.target_panel_file)

Fit and evaluate¶

One LinearRegression (on standardized features, via a StandardScaler pipeline — needed so coefficient magnitude is a meaningful importance signal later, without changing the predictions themselves) per (target, horizon) cell, trained on data before the validation cutoff and scored on the validation period only (test is reserved — see docs/modeling_plan.md).

def make_model():
    return make_pipeline(StandardScaler(), LinearRegression())


def importance_fn(model, feature_names):
    coefs = model.named_steps["linearregression"].coef_
    return pd.Series(np.abs(coefs), index=feature_names)


results, val_predictions, importances = fit_and_evaluate(panel, make_model, importance_fn)

save_scenario_metrics(
    paths,
    scenario_id=SCENARIO_ID,
    title=MODEL_LABEL,
    description=(
        "Linear regression (standardized features) on seasonality (daily/annual) + "
        "short lags (1h, 2h, 24h, 48h) + load-only weekday features. No weather/capacity data."
    ),
    notebook="04_baseline_linear_regression",
    valid=True,
    results=results,
)
print(f"Saved -> {paths.scenario_results_file(SCENARIO_ID)}")

Actual vs. predicted — scatter, full validation period¶

The 1:1 line marks perfect agreement; a cloud that consistently sits off to one side (rather than scattered evenly around it) reveals systematic bias — e.g. points below the line at high actual values mean peaks are under-predicted.

Error analysis — full validation period¶

7-day rolling mean absolute error over the full ~2-year validation period, one line per horizon. Reveals whether error is roughly constant over time (homoskedastic) or clusters seasonally / grows with some regime — e.g. PV error should track the summer/winter irradiance swing.

Scenario overview: comparison tables

One table per headline variable, one row per scenario. Valid marks whether a scenario is a fair forecast — i.e. doesn’t use information that wouldn’t really be available at forecast time. Every scenario so far uses only lagged/calendar features (see docs/modeling_plan.md); this only turns to ⚠️ once a scenario uses perfect-foresight weather (phase 2) or an unvalidated real forecast (phase 3).

Rows are sorted by MAE at the longest horizon (14d, best first) — the project’s main interest is the longer lead times (see docs/modeling_plan.md). See Scenario overview: error by lead time for how MAE/RMSE evolve with forecast horizon.
